## BIP39从2048个词汇中随机选择12(或24)个词汇，钱包安全吗，会碰撞吗

2048 = 2^11

```
2048^12 = (2^11)^12 = 2^132
2048^24 = (2^11)^24 = 2^264
```
int256范围： -2^255 ~ 2^255 - 1

但 BIP39 助记词里包含校验位，所以真正的熵不是全部组合数：

```
12 词助记词：128 位熵 + 4 位校验 = 132 位
24 词助记词：256 位熵 + 8 位校验 = 264 位
```

因此有效安全强度是：

```
12 词 BIP39 ≈ 2^128
24 词 BIP39 ≈ 2^256
```
